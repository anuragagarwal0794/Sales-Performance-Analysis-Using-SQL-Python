# Sales-Performance-Analysis-Using-SQL-Python
Sales Performance Analysis using SQL, Python, and Power BI. An end-to-end data analytics project featuring data extraction, SQL analysis, Python visualizations, and an interactive Power BI dashboard.
Overview

This project demonstrates an end-to-end sales analytics workflow using SQL, Python, and Power BI. The dataset was imported into MySQL, analyzed using SQL queries, processed with Python (Pandas), visualized using Matplotlib, and finally transformed into an interactive Power BI dashboard.

Objectives
Analyze sales performance across products, categories, and cities.
Identify top-performing products by revenue.
Compare revenue distribution across categories.
Visualize key business metrics and trends.
Build an interactive dashboard for business decision-making.
